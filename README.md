# Electricity Bill Management System


## Problem Statement

**Case Study 18: Phase 1 – Analysis**

Electricity boards generate monthly bills for consumers based on the units of electricity consumed. 

The system should:
* Record electricity units
* Calculate bill amount
* Generate bill receipt

## ⚙️ System Architecture (Proposed)
To efficiently manage the billing process, the system is structured around key entities:
* **`Consumer`**: Manages customer details and historical data.
* **`Tariff`**: Defines the rate slabs for calculation.
* **`BillingSystem`**: Contains the core logic for calculating the final amount based on units consumed.
* **`FileManager`**: Handles the reading and writing of data and generating the final receipt.
